# 스마트24 82만 키워드 → 지역 대표 URL 연결 진단 (2026-11-12)

## 운영 Supabase 읽기 전용 검사
- `public.region_service_keywords` 정확한 COUNT(*): **823,160**. 서비스별 대리운전 **411,580**, 탁송 **411,580**.
- 각 서비스의 고유 `region_name` **20,579**, `canonical_path` **20,579** (서비스 합계 41,158).
- 두 서비스 각각 **411,240**개 키워드의 `canonical_path`는 `/keyword-search/?q=...` 검색 파라미터로 기록됨. 전체 **822,480**개.
- 두 서비스 각각 **340**개 키워드만 `/daeri/...` 또는 `/taksong/...` 지역 대표 경로로 기록됨. 전체 **680**개.
- **DB는 이 작업에서 수정하지 않음**: 원본 823,160개는 안전하게 보존됨.

## 적용
1. `/region-live/?q=...` API 결과에 저장된 `path`를 그대로 신뢰하지 않고 법정 지역 등록부(`regionByFullName`)와 `servicePath`를 사용해 실제 대표 URL로 연결.
2. `/keyword-search/?q=...` 유입 시 DB에 존재하는 각 서비스별 20개 키워드 수식어를 인식해 기존 지역 대표 페이지로 이동. 모호하거나 매칭되지 않는 지역은 임의 URL 생성하지 않음.
3. 홈페이지에서 개별 내용이 검토된 지역·서비스 안내(`data/priority-regions.json`)를 검색엔진이 발견 가능한 HTML 내부 링크로 추가. 출처가 확인되지 않은 운행 후기는 생성하지 않음.
4. 기존 `noindex` 초안·지역 대표 canonical·이미지 정책·1811-4294·운행기록은 변경하지 않음.
