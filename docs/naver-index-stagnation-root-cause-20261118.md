# 네이버 클릭·색인 정체 원인 분리 (2026-11-18)

## 확인된 내용
- 사용자 관측: 현재 실제 클릭과 색인 개선 확인되지 않음. 서치어드바이저 인증 화면에 ChatGPT가 직접 접근한 것이 아님.
- 갱신일 2026-11-16의 최근 30일 PC+모바일 자료에서 표시된 웹문서 URL 14행은 네이버 색인된 14개 URL이 아님.
- 전국 탁송·대리운전 허브의 시·군·구 전체 템플릿 링크는 지역 고유자료가 없는 링크까지 과도하게 연결하고 있었음. 이 결함은 수정 가능하나, 네이버 색인 제외의 확정 원인이라고 단정 불가.
- 네이버 공식 가이드: 수집 성공과 색인은 다르며, 수집된 문서도 색인에서 선택되지 않을 수 있음.

## 실제 수정
1. 전국 탁송·대리운전 허브의 무차별 시·군·구 링크를 기존 소스 검토 지역(59건, 종류별 필터)으로 제한.
2. 전국 17개 시·도 안내, 전체 지역 찾기, 실제 완료 기록, 예상요금과 전화 상담, 산행·자전거 링크 유지.
3. 기존 행정구역 URL과 상세 페이지, 사이트맵, robots, canonical, 2,591건 원본은 보존.
4. 운영 서버 제목·설명을 로컬 승인 title/description과 정확히 비교하도록 live audit 강화.
5. 소유자 공식 진단에서 색인 건수가 아직 확인되지 않았으므로 과거의 추정 14건을 실제 색인 베이스라인에서 제외.

## 정확한 색인 실패 유형별 진단
| 네이버 URL 검사 결과 | 가능한 원인 범주 | 후속 검증 |
|---|---|---|
| 수집 실패·차단·404 | 접근성 또는 크롤링 기술 오류 | Yeti HTTP·robots·redirect·로그 확인 |
| 수집 완료, 색인 가능, 미색인 | 색인 후보에서 선택되지 않음, 원인 미확정 | 유사본문·고유정보·대표 URL과 실제 원본 비교 |
| 색인됨, 노출 부족 | 검색어·본문 의도와 경쟁력 검토 | URL/검색어 표를 별도 확인 |
| 노출 많음, 클릭 없음 | 노출 위치·검색 의도 불일치 가능 | 강릉 등 검색결과 실물 확인 |
| 11월 17일 수정 후 11월 16일 데이터 그대로 | 변경 전 데이터 | 재수집·리포트 갱신 이후 확인 |

## 최종 성과 판정
실제 네이버 웹검색 PC+모바일 최근 30일의 클릭·노출·CTR, URL 검사 색인/최근수집일을 별도 측정.
URL TOP 14행과 검색어 TOP 30은 개별 쿼리×URL 관계를 증명하지 않는다.
클릭수·평균순위·색인 숫자를 추정하지 않는다. 30일 이동 구간 겹침과 보고 지연을 고려한다.
자동 HTTP/SEO 테스트의 성공은 공식 네이버 색인·노출 증가가 아니다.
