# 스마트24 소스 근거 재검토 및 네이버 실제 검색성과 확인 (2026-11-17)

이 문서는 내부 자료의 **검토 우선순위**를 정하고 네이버의 **실제 공식 지표**를 구분하기 위한 운영 절차입니다. 자동 진단 점수와 사이트맵 URL 수는 네이버 색인 수가 아닙니다.

## 1. 지역 미분류 과거 운행 2,183건

- 원본 `data/ride-history.json` 2,591건은 변경하지 않습니다.
- 원본과 보관된 ID를 교차 확인했을 때 기존 지역 분류는 408건이고 미분류는 2,183건입니다.
- `scripts/triage-unresolved-rides-and-content.mjs`가 원본 **출발/도착 메모에 실제로 쓰인 공식 시·군 명칭**을 조회해 검토 후보를 만듭니다.
- 지역명이 여러 개면 충돌 검토, 목적지에만 있으면 목적지 후보 검토, 명확한 지명이 없다면 미확정으로 유지합니다.
- **검토표의 지역명은 실제 운행 출발지가 아닙니다.** 개별 원본의 도착·출발을 사람이 확인하기 전에는 기존 지역 분류·검색 페이지·후기를 절대 수정하지 않습니다.
- 출력 `ride-2183-original-evidence-triage.csv/json`에는 기록 ID, 서비스, 날짜, 시·군 수준의 후보와 검토 상태만 있으며 원본의 세부 주소나 고객정보는 옮기지 않습니다.

## 2. 고유 원고 2,535건

- 원본 지역 안내 2,900건의 동일한 콘텐츠 평가표를 사용합니다. 변경 전 기준 통과 365건, 재검토 2,535건을 보존합니다.
- `content-2535-evidence-first-review.csv/json`은 재검토 원고의 근거를 먼저 점검할 수 있도록 정렬합니다.
- 우선순위: (1) 사람이 이미 대조한 공개 블로그 원문, (2) 같은 지역·서비스로 분류된 실제 보관 운행자료, (3) 기존 검토된 지역 준비사항, (4) 아직 독립 근거가 없는 원고.
- **블로그 지역 안내는 개별 완료 운행 증빙이 아닙니다.** 보관기록의 지역 분류도 출발지와 목적지의 구체적 일치 여부를 대체하지 않습니다.
- 지역별 차량 키·주차장·반출 승인·수령 시각 같은 고유 조건이 해당 지역에서 실제 적용되는지 근거를 확보한 뒤 기존 대표 페이지 원고에 반영합니다. 템플릿 반복, 허위 후기, 제조사 공식 제휴/고정 요금은 사용하지 않습니다.
- 검색엔진에서 읽는 HTML 본문·title·H1·canonical·사이트맵·관련 링크는 별도로 테스트해야 합니다.

## 3. 네이버 실제 색인·노출·클릭·CTR

기존 소유자 제공 자료:
- **2026-11-06** 최근 30일 보고: 클릭 **77**, 노출 약 **2,000**, CTR **3.8%**.
- 이전 사이트 진단에서 정상 색인 **14**, 수집제한 **1**, 색인 제외 **0**으로 보고됐지만 **관측 날짜는 불명**.
- 클릭에는 소유자의 검색 노출 확인을 위한 자체 클릭이 포함될 수 있어 고객 유입이나 전화 상담 수를 뜻하지 않습니다.

현재 소유자 인증 최신 데이터가 없으면 **색인·노출·클릭·CTR 증가/감소를 계산하지 않습니다**. 14개는 관측일 불명이라 나중에 최신 색인 수가 들어오더라도 단순 차이로 '공식 증가'라고 발표하지 않습니다.

최신 자료가 확보된 경우에만 다음 입력을 사용합니다.

1. 네이버 서치어드바이저의 **사이트 진단**에서 실제 정상 색인·수집제한·색인 제외와 관측일을 확보합니다.
2. **검색 노출/클릭 리포트**에서 페이지별 및 사이트 전체의 기간, 클릭, 노출, CTR을 확보합니다. 최근 30일끼리 비교하면 기간이 겹칠 수 있다는 점을 기록하고, 같은 길이의 서로 겹치지 않는 기간을 추가 확보하는 것이 더 좋습니다.
3. 소유자 확인을 마친 값만 `NAVER_SEARCHADVISOR_SNAPSHOT_FILE` 환경변수로 `scripts/report-naver-official-scorecard.mjs`에 전달합니다. 외부 검색 결과·GitHub 통과·IndexNow 알림·Google Search Console 수치를 네이버 통계로 대체하지 않습니다.

입력 JSON 예시 구조(아래 숫자는 **형식 설명용 예시가 아니라 빈 필드**, 실제 소유자 확인값으로 채워야 함):

```json
{
  "sourceType": "owner_reported_naver_searchadvisor",
  "observedAt": "YYYY-MM-DD",
  "indexed": null,
  "collectionLimited": null,
  "excluded": null,
  "search": {
    "period": "최근 30일",
    "updatedAt": "YYYY-MM-DD",
    "clicks": null,
    "impressions": null
  }
}
```

검증은 `node scripts/report-naver-official-scorecard.mjs`로 실행하며 결과는 `naver-official-scorecard.json/md`에 저장합니다. `null`이나 자리표시 문자는 유효한 최신값이 아닙니다. 인증된 최신 값을 받기 전에는 샘플을 입력으로 사용하지 않습니다.
