# 자동차 관련 업체 탁송·상담 유입 측정 설계

스마트24 전국자동차탁송 서비스 SEO 확장 및 전화 상담 유입 구분을 위한 작업 기준입니다.

## 업종 분류
- 정비·공업사: 공업사탁송, 모터스탁송, 정비입고탁송, 정비출고탁송, 판금도색탁송
- 자동차검사: 정기검사탁송, 종합검사탁송, 구조변경탁송, 튜닝검사탁송, 배출가스검사탁송
- 관리: 디테일링탁송, 손세차탁송, 광택탁송, 실내크리닝탁송, 유리막코팅탁송
- 시공·장착: 썬팅탁송, 틴팅탁송, 블랙박스장착탁송, 내비게이션장착탁송, 네비장착탁송, PPF탁송, 랩핑탁송, 후방카메라장착탁송, 하이패스장착탁송, 카오디오탁송
- 기타: 타이어교체탁송, 휠수리탁송, 배터리교체탁송, 신차검수탁송, 차량상품화탁송

'리테일'은 오기였고 고객 요청 용어는 '디테일링'입니다. 독일공업 및 마너스 등 업체의 콜 유입 경로는 확인되지 않았으므로 블로그·홈페이지 유입을 단정하지 않습니다.

## 검색 페이지 품질
지역명과 모든 업종명을 기계적으로 결합한 페이지를 대량 생성하지 않습니다. 업종별 실용적인 안내, 실제 운행 사례(확인된 것만), 시·군·구별 유용한 안내를 구성하고 관련 페이지를 내부 연결합니다. 시공/검사를 직접 제공한다고 주장하지 않습니다. 운행 불가 차량은 견인이 필요할 수 있습니다.

## 전화 유입 측정
대표번호는 변경하지 않습니다. 전화 버튼의 클릭 이벤트만으로 통화 연결·완료·계약을 단정하지 않습니다. 향후 구현 시 각 전화 링크에 개인정보를 포함하지 않는 page_path, service_category, placement 이벤트를 부여하고 분석 도구 설정 및 개인정보 고지 상태를 점검합니다. 블로그는 외부 전화 버튼 클릭 추적에 제약이 있으므로 상담 접수 시 '블로그/홈페이지/기타/모름' 선택 기록을 병행합니다.

## 배포 전 확인
- server.js 및 기존 경로/계산기/상담/운행기록 회귀 테스트
- canonical, title/H1, sitemap, robots, 지역 내부 링크 점검
- 기존 전화번호 유지
- main 병합 전 리뷰, Cloudtype 자동 배포 영향 확인
