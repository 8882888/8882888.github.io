# 고수·케이·스마트24 공개 사이트 비교와 개선안

점검일: 2026-11-12 (한국 기준). 대상: gosudaeri.com, kdaeri.com, jeongukdaeri.kr. 케이대리운전은 검색 및 공식 페이지의 브랜드·1666-4255로 확인했습니다. darigo.com과 같은 사이트라고 가정하지 않았습니다.

## 결론

스마트24에도 지역 검색·요금 조회·실제 운행기록이 이미 있습니다. 표본에서 기본 SEO 태그가 누락되어 경쟁사에 뒤처진다고 볼 근거는 발견하지 못했습니다. 개선 초점은 신규 URL 수 확대보다 기존 지역 페이지의 정보 중복을 줄이고, 요금 확인·이동 방향이 정확한 기록·예약 정보를 쉽게 찾도록 연결하는 것입니다. 이는 공개 페이지에 근거한 개선 판단이며 네이버 순위 상승의 원인을 증명한 결과는 아닙니다.

## HTTP HTML 표본 검사

HTML 7개와 robots.txt 3개, 총 10개 주소를 GET 요청으로 확인했습니다. 각 HTML 표본에 제목·설명·canonical 1개·H1 1개·viewport·tel 링크가 있고, 검사 대상에서 noindex가 검출되지 않았습니다. robots.txt 3개에서 사이트맵 선언을 확인했습니다. 사이트맵에 적힌 모든 URL을 검사한 것은 아닙니다. 사이트맵 선언만으로 로봇 수집 허용이나 색인을 보장하지 않습니다.

| 첫 화면 HTML | 응답 본문 크기 | 추출된 동일 호스트 링크 수(중복 제거) |
|---|---:|---:|
| 고수 | 40,088 바이트 | 57 |
| 케이 | 119,109 바이트 | 39 |
| 스마트24 | 226,003 바이트 | 260 |

이 수치는 한 번의 응답을 기준으로 합니다. HTML 크기는 전송 압축 크기·전체 리소스 크기·모바일 로딩 시간과 다르며, 링크 수가 많거나 적다는 사실만으로 SEO 우열을 판정하지 않습니다. 스마트24 홈은 정보량이 많으므로 핵심 예약 동선을 먼저 배치하고 세부 안내를 관련 페이지로 정리할 여지가 있다는 판단입니다. 이번 패키지는 운영 홈을 수정하지 않았습니다.

케이의 강남 페이지는 canonical의 한글 표기와 HTTP 요청 URL의 퍼센트 인코딩 표기가 달랐지만 같은 주소입니다. 이를 오류로 보고하지 않도록 검사기를 보완했습니다. 고수의 첫 일반 요청은 403이었으나 명시적 점검 User-Agent를 사용한 후속 표본은 200이었습니다. 일시적인 403을 사이트 장애나 검색 차단으로 단정하지 않습니다.

웹 검색 도구의 부산 페이지 제목과 직접 HTTP 응답 제목이 달랐습니다. 검색 도구 캐시·수집시점·배포시점 차이일 수 있으며 원인은 확인하지 못했습니다. 숫자와 태그 판정은 reports/public-audit.json의 직접 HTTP 응답을 기준으로 합니다.

## v2 구현

1. 기존 대표 경로를 `existingPath`로 등록하면 신규 경로를 기존 URL로 301 연결하고 신규 사이트맵에서 제외합니다.
2. 기존 본문 교체용 블록은 요금조회 → 장소별 준비 → 실제 기록 표 → 예약 질문으로 구성합니다. 이미 있는 기록/예약 영역을 대체하며 같은 내용을 하단에 중복 추가하지 않습니다.
3. 운행 사례는 지역 ID, 서비스, 날짜, 원문, 공개 여부가 모두 검증된 기록만 표시합니다. 출발 기록과 도착 기록을 별도 표시합니다.
4. 같은 별칭이 여러 지역에 있으면 선택 화면으로 분기합니다. 처음 일치하는 지역을 임의로 선택하지 않습니다.
5. 공개 HTML 검사기는 canonical·noindex·H1·모바일 설정·전화 링크·JSON-LD를 재검사합니다. 브라우저 클릭·네이버 순위 측정 도구는 아닙니다.
6. 네이버 비교기는 동일 길이의 겹치지 않는 두 기간 CSV에서 클릭 증가량과 CTR 변화를 계산합니다. 한쪽 기간에 없는 검색어는 미확인으로 남깁니다.

초기 적용 블록: 세종 대리운전, 부산 탁송 2개. 원문 연결은 4건입니다. 초기 사전은 기존 12개 지역에 실제 기록의 출발지 코드인 청주·광주광역시를 더해 14개 지역입니다. 나머지 지역의 새 상세 안내는 미승인 초안이며 검색 공개하지 않습니다. 전체 2,591건 데이터베이스를 읽거나 변경하지 않았습니다.

## 우선 적용 순서

- P0: 기존 /daeri/sejong/, /taksong/busan/ 본문의 중복된 요금·기록·예약 영역을 생성 블록으로 정리. 기존 페이지 제목, 대표 URL, 운행기록 원문, 상위/하위지역 링크 보존.
- P1: 실제 자료가 있는 원주·진주·나주·김천 혁신도시, 기장군, 대구·울산의 기존 경로를 확인한 뒤 같은 방식으로 확장.
